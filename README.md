#### Используемые технологии
* Само приложение реализовано с помощью Visual Studio и WPF (.NET Framework)
* Навигация между страницами реализована кнопками и соответствующими им обработчиками событий:
  - ```nextFuncBtn``` -> ```nextFuncBtn_Click```
  - ```bsckBtn``` -> ```backBtn_Click```
* Выход из приложения реализован с помощью события ```MainWindow_Closing``` с подтверждающим действие ```MessageBox```
* Подсказки к элементам интерфейса реализованы свойством ```ToolTip```
