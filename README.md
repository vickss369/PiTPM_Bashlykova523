## Ход работы:
### 1. Анализ предметной области
Шифр Виженера — это полиалфавитный метод шифрования, в котором каждая буква исходного текста сдвигается на разное число позиций в алфавите. Величина сдвига определяется соответствующей буквой ключевого слова, которое повторяется или обрезается до длины текста.

Для шифрования и дешифрования используется один и тот же ключ. При этом пробелы и знаки препинания обычно не изменяются. Данный метод является развитием шифра Цезаря и обеспечивает более высокий уровень защиты за счёт переменного сдвига символов.

### 4. Отладка разработанного WPF-приложения
**Используемые средства отладки:**
1. Точки останова
Точки останова были установлены в методах `EncryptVigenere` и `DecryptVigenere` на участках обработки символов входной строки. Это позволило приостановить выполнение программы в момент обработки каждого символа и проанализировать состояние переменных.

2. Пошаговое выполнение (Step Into / Step Over)
* F10 (Step Over) использовался для поэтапного выполнения цикла обработки строки без входа в вызываемые методы
* F11 (Step Into) применялся для перехода внутрь методов вычисления индексов и анализа работы алгоритма

3. Просмотр значений переменных
Использовались окна отладки Visual Studio:
* Locals — отображение всех локальных переменных в текущем контексте выполнения
* Watch — контроль значений ключевых переменных (symbol, alphabet, textPos, keyChar, keyPos, newPos)

В ходе отладки была обнаружена проблема со сдвигами символов: ожидаемый результат не соответствовал фактическому.

Путём отладки с перечисленными выше используемыми средствами отладки было установлено следующее:
* char.ToUpper(symbol) для символа «Ё» корректно возвращает «Ё»
* Однако RussianAlphabet.IndexOf('Ё') возвращает значение -1

Дополнительный анализ переменных в цикле foreach показал, что символ «Ё» отсутствует в строке русского алфавита, используемой для вычисления позиции символа и сдвига.

**Обнаруженная ошибка**

После отладки кода выяснилось, что проблема была в отсутствии буквы Ё в заданном алфавите, хотя расчёт ожидаемого результата проводился исходя из всех 33 букв русского алфавита.

**Исправление**

В константу `RussianAlphabet` была добавлена буква Ё. После внесения исправления алгоритм шифрования и дешифрования стал корректно обрабатывать полный русский алфавит.

#### Описание автоматизированных тестов
**Модуль шифрования**

`TC01_EnglishEncrypt_ShouldReturnCorrectResult`

Проверяется корректность шифрования английского текста. Тест проходит успешно при корректной реализации алгоритма Виженера для английского алфавита.

`TC03_WithSpaces_ShouldPreserveSpaces`

Проверяется шифрование русского текста с сохранением пробелов. Ожидается, что пробелы сохраняются без изменений, а остальные символы корректно шифруются.

До добавления буквы Ё в алфавит тест не проходил, так как в процессе вычисления индексов происходило смещение символов русского алфавита. Из-за отсутствия Ё в алфавите нарушалась структура индексации, и результат шифрования не совпадал с ожидаемым.
После исправления алфавита тест стал соответствовать ожидаемому результату.

`TC04_EmptyText_ShouldReturnErrorMessage`

Проверяется обработка пустого текста. При вводе пустой строки метод должен вернуть сообщение об ошибке. Тест подтверждает наличие в ответе сообщения о некорректном вводе.

`TC06_WithPunctuation_ShouldPreserveSymbols`

Проверяется сохранение знаков препинания при шифровании. Специальные символы не должны изменяться в процессе обработки текста. Тест подтверждает корректную обработку небуквенных символов.

`TC07_LongKey_ShouldBeTrimmed`

Проверяется работа алгоритма при ключе, длина которого превышает длину текста. Ключ должен обрезаться и циклически повторяться.

До добавления буквы «Ё» тест не проходил, так как из-за неполного русского алфавита происходило смещение индексов символов. Это приводило к неверному результату шифрования. После исправления алфавита и включения «Ё» результат стал соответствовать ожидаемому.

**Модуль дешифрования**

`TC02_RussianDecrypt_ShouldDecryptCorrectly`

Проверяется корректность обратного преобразования - зашифрованный текст расшифровывается и должен полностью совпасть с исходным. Тест подтверждает обратимость алгоритма.

`TC05_EmptyKey_ShouldNotReturnValidResult`

Проверяется обработка некорректного ключа (пустое значение). Ожидается, что результат не будет совпадать с исходным текстом.

`TC09_EmptyKey_ShouldReturnErrorMessage`

Проверяется возврат информативного сообщения при пустом ключе. В результате выполнения должно присутствовать сообщение, содержащее информацию о некорректном вводе ключа.

`TCDecrypt_ShouldPreserveCase`

Проверяется сохранение регистра символов при дешифровании. Заглавные буквы должны оставаться заглавными, а строчные — строчными. Дополнительно проверяется, что регистр не преобразуется полностью в нижний.
