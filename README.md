# Поддержка и тестирование программных модулей
## Практическая работа №7.1 
Отладка программы различным способом

---
### Цель работы:
Произвести процедуру отладки программного обеспечения встроенными средствами среды программирования Microsoft Visual Studio. 

---
### Используемые способы отладки
1. Точки останова - полезны для пошагового выполнения кода и остановки в определённом, потенциально проблемном моменте: например, внутри метода SendMessage.
2. Пошаговое выполнение кода - позволяет медленно «пройтись» по циклу for, наблюдая за изменениями.
  * F10 (Step Over) — выполнить строку и перейти к следующей
  * F11 (Step Into) — зайти внутрь метода SendMessage
  * Shift + F11 (Step Out) — выйти из текущего метода обратно в Main.
3. Просмотр значений - наводим мышку на переменную name или letters[i] во время остановки на точке останова — всплывает окошко со значением. Очень удобно проверять, как постепенно растёт строка name от "f" до "fred smith".
4. Окна отладки
* Locals — автоматически показывает все локальные переменные: letters, name, a, i, а также параметры name и msg внутри метода
* Watch — можно добавить выражения для наблюдения, например: name, a[i], или даже "Длина имени: " + name.Length
* Autos — показывает переменные, которые используются на текущей строке
5. Запуск в режиме отладки (Fn + F5) и Перезапуск (Ctrl + Shift + Fn + F5).
6. Стек вызовов - показывает последовательность вызовов: Main() → SendMessage(). Полезно понимать, откуда был вызван метод.
