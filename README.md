### Ход работы:
#### Unit-тесты

<img width="1350" height="361" alt="image" src="https://github.com/user-attachments/assets/aab11086-0936-477e-9c8f-18149131b444" />

* ```Test_Om_AllCalculations_Correct``` - проверяет корректность вычисления всех трёх величин по закону Ома: силы тока, напряжения и сопротивления.
* ```Test_Om_Errors_ShouldReturnMessages``` - проверяет обработку ошибок: деление на ноль, отсутствие выбранной функции и некорректное название функции. В каждом случае ожидается, что функция вернёт false, а строка ошибки будет содержать соответствующее сообщение ("Деление", "Выберите", "Неизвестная").
* ```Test_Om_WrongExpected_ShouldFail``` - намеренно проверяет неверный ожидаемый результат, чтобы проверить работу со значениями.
