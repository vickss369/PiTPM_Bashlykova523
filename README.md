# Поддержка и тестирование программных модулей
## Практическая работа №7.1 
Отладка программы различным способом

---
### Цель работы:
Произвести процедуру отладки программного обеспечения встроенными средствами среды программирования Microsoft Visual Studio. 

---
### Используемые способы отладки
1. Точки останова - полезны для пошагового выполнения кода и остановки в определённом, потенциально проблемном моменте: чтобы посмотреть значения объекта theGalaxy и увидеть, как работает switch для разных букв.
2. Пошаговое выполнение кода - позволяет медленно «пройтись» по циклу foreach и конструктору, наблюдая за изменениями.
  * F10 (Step Over) — выполнить строку и перейти к следующей
  * F11 (Step Into) — зайти внутрь метода или конструктора
3. Просмотр значений - наводим мышку на переменную во время остановки на точке останова — всплывает окошко со значением. Очень удобно проверять, что лежит в GalaxyType.MyGType.
4. Запуск в режиме отладки (Fn + F5) и Перезапуск (Ctrl + Shift + Fn + F5) после исправления ошибки (например, изменения типа свойства с object на GType или исправления case 'l' на case 'I').
5. Редактирование кода во время отладки на остановленной строке и продолжение выполнение.
